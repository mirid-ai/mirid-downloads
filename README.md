# Mirid downloads

Public release packages and corresponding source for [Mirid](https://mirid.ai/).

- [All downloads and platform requirements](https://mirid.ai/download/)
- [Try the browser preview](https://mirid.ai/try/)
- [Windows 1.0.13](https://mirid.ai/access/)
- [iOS developer source preview](https://mirid.ai/download/#ios)

The Linux desktop preview is qualified for Debian 13 on x86_64 and uses hosted APIs such as NanoGPT and OpenRouter. Each Linux release includes the tested desktop executable, corresponding application source, an offline Python dependency bundle, installation instructions and SHA-256 checksums. See the release notes for prerequisites and limitations.

The iOS preview requires a Mac and Xcode to build and sign. It is not a signed iPhone installer, and no TestFlight invitation is available yet.

Mirid is free software under AGPL-3.0. Provider accounts and usage charges are separate. This repository distributes public release packages; it does not contain private development history, credentials or user data.
